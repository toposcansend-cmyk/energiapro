## Sobre o EnergiaPro

**EnergiaPro** é um produto desenvolvido pela Toposcan para a **Nexum** (cliente/parceira).

- **App:** EnergiaPro pertence à **Nexum**
- **Logo no app:** Nexum (`img/logo-nexum.png`)
- **Repositório:** toposcansend-cmyk/energiapro (conta GitHub da Toposcan)

### O que é o EnergiaPro

Ferramenta web de eficiência energética para comércios brasileiros, com IA (MiniMax M2.7) para análise de contas de energia, mapeamento de equipamentos e geração de diagnósticos.

### Stack

- Frontend: HTML5, CSS3, JavaScript vanilla (zero dependências)
- IA: MiniMax M2.7 (texto + visão)
- Persistência: localStorage (MVP)
- Deploy: GitHub Pages

### Fluxo do App (5 etapas)

1. Cadastro & Perfil do estabelecimento
2. Análise de conta de energia (foto → OCR com IA)
3. Mapeamento de equipamentos (foto → IA ou manual)
4. Diagnóstico & Insights (relatório gerado por IA)
5. Painel de Gestão (dashboard com KPIs e histórico)
