## 🛠️ Como produzir o vídeo a partir dos HTMLs

### Opção A — Gravação de tela (mais rápida, hoje)

1. Abra `reels-animacao.html` no Chrome em **tela cheia** (F11).
2. Ajuste o zoom para a animação ocupar exatamente o frame de 1080x1920 (a página já vem escalada — remova o `transform: scale(0.42)` no CSS antes de gravar para resolução 1:1; ou grave em 0.42 e escale na edição).
3. Use **OBS Studio** (free) com captura de janela em 1080x1920 @ 30fps.
4. Clique em **REINICIAR · GRAVAR** logo após começar a gravar.
5. Exporte em MP4 H.264.
6. Edite no CapCut: adicione áudio (sugestões abaixo), corte para 15s exatos.

### Opção B — Importe os HTMLs para After Effects / Premiere

- Renderize cada cena como PNG sequence usando uma extensão como Puppeteer.
- Importe na timeline e adicione transições.

### Opção C — Recrie no Canva/Figma (sem código)

Use as especificações da seção "Diretrizes visuais" + o roteiro acima. Os HTMLs viram referência visual.
