# 🎬 Prompts para gerar o Reels TopoScan em IA de vídeo

Funciona em: **Sora, Veo 3, Runway Gen-4, Pika, Kling, Hailuo, Luma Dream Machine**.

> **Dica de uso:** comece pelo "PROMPT MESTRE" (15s). Se a ferramenta só gera 5–8s, use os "PROMPTS POR CENA" e junta no CapCut.

## 🔥 PROMPT MESTRE — 15 segundos (cole inteiro)

```

MID (3–6s): Thousands of glowing blue and white pixel-sized points start
```

## ⚙️ Parâmetros técnicos (cole em campos específicos da ferramenta)

| Campo | Valor |
|---|---|
| Aspect ratio | **9:16** (vertical) |
| Resolution | **1080x1920** |
| Duration | **15s** (mestre) ou **5s** (por cena) |
| Frame rate | **30fps** (ou 24fps se a ferramenta sugerir cinematográfico) |
| Style | `cinematic`, `motion graphics`, `tech brand`, `point cloud`, `LiDAR aesthetic` |
| Camera | `locked frame`, leve `slow push-in` na cena 3 |
| Lighting | `dark`, `low-key`, `blue rim light`, `particle glow` |
| Negative prompt (se houver) | `people, faces, real photography, watermark, logo, busy background, daylight, bright colors, characters, text errors, distorted text` |

## 🚀 Por ferramenta — dicas específicas

### Sora (OpenAI)
- Cola o **PROMPT MESTRE em inglês** inteiro.
- Em "Style preset" escolhe **Cinematic** ou **3D**.
- Se rejeitar o texto on-screen ("AMANHÃ?", "MILÍMETRO."), adiciona depois no CapCut.

### Veo 3 (Google)
- Suporta áudio gerado. Adicione no final do prompt:
  `Audio: deep cinematic ambient drone with subtle mechanical clicks and a low sub-bass build, ending in a single satisfying low boom.`
- Veo 3 também aceita prompts longos — cola o mestre inteiro.

### Runway Gen-4 / Gen-4 Turbo
- Quebra em 4 prompts de 5s cada (use a versão "POR CENA").
- Em **Camera Motion** escolhe `Static` para 1, 2, 4 e `Slow zoom in` para 3.
- Junta no Runway timeline ou no CapCut.

### Pika 2.x
- Prefere prompts mais curtos. Pega só o PRIMEIRO PARÁGRAFO de cada cena.
- Em "Negative prompt" cola: `people, real photo, watermark, low quality, blurry text`.

### Kling 2 / 2.1
- Aceita prompts longos em chinês/inglês — usa o mestre EN.
- Em "Mode" escolhe **Professional / High Quality**.
- Setting: **Cinematic camera**.

### Hailuo / MiniMax
- Usa **Image-to-Video** se possível: gera primeiro 4 imagens estáticas com Midjourney/DALL-E usando os prompts de cena, depois anima cada uma.
- Image prompt sugerido: `vertical 9:16, [scene description], dark cinematic tech aesthetic, electric blue particle accents, premium brand visual`.

### Luma Dream Machine
- Faz cena por cena (5s cada).
- Em "Enhance prompt" deixa **ON**.
- Camera: `Static` para 1, 2, 4 — `Push In` para 3.

## 🔁 Variações para A/B testing

Se quiser testar versões diferentes, troca o **hook** (cena 1) por:

**Variação A — Pergunta direta (atual):**
```
E SE DESAPARECESSE AMANHÃ?
```

**Variação B — Provocação:**
```
A SUA HISTÓRIA TEM PRAZO DE VALIDADE?
```

**Variação C — Afirmativa poética:**
```
O TEMPO APAGA TUDO. MENOS DADOS.
```

**Variação D — Pergunta + nicho engenharia:**
```
QUANTOS MILÍMETROS VOCÊ ESTÁ DISPOSTO A PERDER?
```

E o CTA final (cena 4) pode virar:
```
TOPOSCAN. CADA MILÍMETRO IMPORTA.
```
ou
```
TOPOSCAN. ESCANEAMOS A REALIDADE.
```

## ✅ Checklist final antes de postar

- [ ] Vídeo tem **15s** exatos (Reels engaja melhor entre 7–15s).
- [ ] **Som ligado** (sem voz humana, só ambient/tech).
- [ ] **Capa do Reels**: usa o frame da cena 3 (catedral em pontos) — performa melhor que abertura escura.
- [ ] **Legenda** vem do `INSTRUCOES-CELULAR.md`.
- [ ] **Hashtags** no 1º comentário (não na legenda — dá mais alcance).
- [ ] **Marca localização** e perfis relevantes (se igreja real, marca a paróquia).
- [ ] **Compartilha no feed principal** também (ligado por padrão).
