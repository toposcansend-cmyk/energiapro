## ⚙️ Parâmetros técnicos para preencher na ferramenta

| Campo | Valor |
|---|---|
| Proporção / Aspect ratio | **9:16 (vertical)** |
| Resolução | **1080 x 1920** |
| Duração | **15s** (mestre) ou **5s** por cena |
| Frame rate | **30fps** |
| Estilo | `cinematográfico`, `motion graphics`, `marca tech`, `nuvem de pontos`, `estética LiDAR` |
| Câmera | `fixa` em quase tudo, `push-in lento` na cena 3 |
| Iluminação | `escura`, `low-key`, `glow azul`, `partículas brilhantes` |
| Negative prompt | `pessoas, rostos, fotografia real, marca d'água, logos de terceiros, fundo claro, cores quentes, luz do dia, texto distorcido, baixa qualidade` |

## 📋 Como usar cena por cena

1. Gera cena 1 → baixa o MP4.
2. Gera cena 2 → baixa.
3. Gera cena 3 → baixa.
4. Gera cena 4 → baixa.
5. Abre CapCut → novo projeto → importa os 4 vídeos na ordem.
6. Garante proporção 9:16.
7. Adiciona transições entre clipes (Glitch ou Dissolução, 0.3s).
8. Adiciona áudio livre do banco do CapCut (busca "cinematic tech" ou "ambient data").
9. Exporta 1080p 30fps.
